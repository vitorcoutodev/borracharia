### No início

O sistema poderá ter integração oficial com o WhatsApp para automatizar:

- Confirmação de atendimento

# 📱 FUNCIONAMENTO NO CELULAR

Como o sistema será utilizado principalmente pelo celular, as telas serão organizadas para facilitar o uso no telefone.

As mesmas funções também poderão ser utilizadas pelo computador.

### A ideia é:

**Abrir → encontrar o cliente → registrar o serviço → registrar o pagamento → finalizar.**

Tudo de forma simples e rápida.

---

# 💡 RESUMO DO SISTEMA

O sistema terá como principais áreas:

**CLIENTES**  
Cadastro e consulta dos clientes.

**ATENDIMENTOS**  
Registro dos serviços realizados.

**PLANOS**  
Controle dos 3 planos e dos períodos de 30 dias.

**PAGAMENTOS**  
Registro de valores pagos ou pendentes.

**COBRANÇAS**  
Visualização dos clientes que possuem valores em aberto.

**HISTÓRICO**  
Registro dos serviços realizados para cada cliente.

**WHATSAPP**  
Facilitar cobranças, mensagens e futuramente automações.

**PROMOÇÕES**  
Divulgação de ofertas para os clientes.

**LOGIN E SEGURANÇA**  
Acesso protegido e recuperação de senha.
